# HealthNexus---A-Healthcare-application-
Stack: React.js, Node.js, Express.js, MongoDB, JWT Auth, Stripe API, Nodemailer, Multer, REST API, MVC Architecture, Designed full-stack healthcare platform with RBAC for 3 user roles, secured 15+ REST APIs using JWT authentication and also built 5-stage  appointment lifecycle with automated email notifications. Integrated Stripe for payments.
